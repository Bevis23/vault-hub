# 安装说明

三种装法，挑一个就行。**仅桌面端**（Windows / macOS / Linux），手机端用不了
（插件依赖 Node 的文件读写与 `obsidian://` 协议）。

---

## 方式一：社区插件市场（推荐）

1. 设置 → 第三方插件 → 关掉「安全模式」
2. 点「浏览」→ 搜 **Vault Workbench**
3. 安装 → 启用

> 关安全模式这一步每个库都要来一次，这是 Obsidian 的安全设计，关一次就永久生效。
> 之后用工作台的「切换到此库」功能，它会自己把插件装进目标库、并登记为已启用，
> 你只需要在这个库第一次打开时点一下这个开关。

---

## 方式二：手动安装

1. 从 [Releases](../../releases) 下载这三个文件：`main.js`、`manifest.json`、`styles.css`
2. 在你的库目录里建好文件夹：`.obsidian/plugins/vault-workbench/`
3. 把三个文件放进去
4. Obsidian 里 `Ctrl + R` 重载 → 设置 → 第三方插件 → 启用 Vault Workbench

> 这个插件是**免构建**的：`main.js` 就是可直接运行的完整代码，不需要 `npm install`。

---

## 方式三：BRAT（尝鲜测试版）

1. 装好 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 并启用
2. BRAT 设置 → Add Beta Plugin → 填本仓库地址
3. 之后 BRAT 会跟着仓库更新

适合想抢先试新功能的同学，缺点是可能撞上没测全的版本。

---

## 打开工作台

三种方式任意一种：

- 点左侧 ribbon 的「布局网格」图标
- 命令面板（`Ctrl + P`）搜「打开库管理工作台」
- 想随时刷新索引：命令面板搜「刷新库索引」

---

## 常见问题

**Q：左边库导航里没有我的某个库？**

自动发现读的是 Obsidian 的仓库清单（`obsidian.json`）。
只有**打开过**的库才会被登记 —— 先在 Obsidian 里打开它一次，
或者到 设置 → 库管理 里手动添加路径。

**Q：那个库显示「未装」是怎么回事？**

那个库里还没有工作台的文件。右键它 →「切换到此库」，
工作台会先把自己装进去再跳过去；装好之后就正常了。

**Q：切过去之后要做什么？**

第一次进某个库，要在 设置 → 第三方插件 关掉「受限模式」一次。
这是 Obsidian 的安全设计（该开关不落在库文件里，任何插件都无法替你预置）。

**Q：它会不会动我别的库的文件？**

浏览是只读的；**只有你在工作台里主动编辑并保存时才会写入**，
而且是原子写（先写临时文件再改名，写一半崩了原文件还在）。
新建 / 重命名 / 删除这些会动库结构的操作，在别的库里是禁用的 ——
会提示你切到那个库去做，避免跨库断链。

完整说明见 README 底部的《会碰到的库外文件》与 **[多库架构设计思考](多库架构设计思考.md)**。
